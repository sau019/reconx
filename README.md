# ☠️ ReconX

**A Web-Based Google Dorking & Reconnaissance Dashboard**

ReconX is a lightweight web-based reconnaissance dashboard designed to simplify domain-based Google Dorking and information gathering for cybersecurity researchers and bug bounty hunters.

Enter a target domain and use predefined search queries to explore publicly indexed information across search engines and external platforms.

## Features

### 1. Google Dorking
- Directory Listing
- Configuration Files
- Database Files
- WordPress Files
- Log Files
- Backup Files
- Login Pages
- Apache Configuration Files
- Robots.txt
- Publicly Exposed Files
- PHP Info
- Open Redirect Parameters
- API Endpoint Discovery
- Git Repository Discovery

### 2. Subdomain & Asset Discovery
- Subdomain Search
- Deep Subdomain Search
- Certificate Transparency Logs
- Archived Files
- Archived Flash Files
- Cloud Storage & S3 Bucket Search

### 3. Third-Party Platform Search
- GitHub
- GitLab
- Git Gist
- Bitbucket
- Atlassian
- Pastebin
- Reddit
- Stack Overflow
- LinkedIn
- YouTube

### 4. External Security Tools
- Shodan
- Censys
- SecurityHeaders
- PublicWWW
- Wayback Machine
- crt.sh

## Installation

Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
```

Navigate to the project directory:

```bash
cd ReconX
```

Open the project in VS Code:

```bash
code .
```

Run `reconxweb.html` using VS Code Live Server or open it in your browser.

## Usage

1. Open ReconX in your browser.
2. Enter the target domain.
3. Select a reconnaissance or Google Dorking category.
4. The corresponding search query opens in an external search engine or platform.
5. Review the publicly available search results manually.

## Important Notes

- ReconX is a reconnaissance dashboard, not an automated vulnerability scanner.
- Search queries are opened on external platforms.
- Results depend on search engine indexing and availability.
- ReconX does not automatically verify vulnerabilities.
- Some external platforms may require authentication.
